# Η βιβλιοθήκη εφαρμογών μου

Προσωπική εφαρμογή παρουσίασης projects για κινητό, με εικόνες, σύντομες ελληνικές περιγραφές και άνοιγμα των διαθέσιμων demos μέσα σε πλήρη οθόνη.

Το MSc demo είναι δημόσιο στο Streamlit και ενσωματώνεται με την επίσημη επιλογή embed=true. Ο κώδικάς του παραμένει ιδιωτικός. Το πλήρες checkpoint έχει μεταφερθεί και επαληθευτεί στο GitHub. Η ενεργοποίηση hosted ανάλυσης εκκρεμεί μέχρι να ενημερωθεί η συνεδρία Streamlit.

Τα screenshots προέρχονται από τα πραγματικά repositories. Όπου δεν υπάρχει screenshot χρησιμοποιείται απλό σύμβολο. Όπου δεν υπάρχει επαληθευμένο online demo προβάλλονται μόνο οι πληροφορίες του project. Η κάρτα της MSc χρησιμοποιεί το πραγματικό διάγραμμα σύγκρισης μοντέλων της διατριβής.

GitHub Pages: main branch, root. Δεν απαιτείται build. Το service worker αποθηκεύει τη βιβλιοθήκη και τις εικόνες για offline περιήγηση. Τα εξωτερικά demos χρειάζονται internet.

## MSc φιλοξενία

Μόνιμη διεύθυνση: https://kq6xh27vecevgjqen26pjr.streamlit.app/

Η εφαρμογή χρησιμοποιεί το εκπαιδευμένο RoBERTa σε έκδοση INT8 για CPU. Οι μετρικές της διατριβής αφορούν το αρχικό μοντέλο FP32. Η βιβλιοθήκη δεν χρησιμοποιεί προσωρινό tunnel του Mac.

Στο iPhone: άνοιγμα της διεύθυνσης GitHub Pages στο Safari, Κοινοποίηση → Προσθήκη στην αρχική οθόνη. Μετά από αναβάθμιση, κλείσιμο και νέο άνοιγμα της εφαρμογής ώστε να φορτωθεί η νεότερη έκδοση.
